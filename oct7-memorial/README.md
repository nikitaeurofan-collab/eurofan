# 7.10.2023: ролик памяти (иврит) для TikTok / Reels

- `oct7_memorial_he_1080x1920.mp4`: готовый ролик, 1080×1920 (9:16), 30 fps, около 44 секунд, H.264 + AAC
- `cover.jpg`: обложка (кадр «לעולם לא נשכח / יהי זכרם ברוך»)
- `make_video.py`: скрипт, которым ролик собран (Pillow + numpy + ffmpeg)

## Пересборка

```
python3 make_video.py --fonts <папка со шрифтами> --out .
```

Нужны шрифты [Frank Ruhl Libre](https://fonts.google.com/specimen/Frank+Ruhl+Libre) и [Heebo](https://fonts.google.com/specimen/Heebo)
(файлы `FrankRuhlLibre[wght].ttf`, `Heebo[wght].ttf`), Noto Color Emoji, Pillow с libraqm, numpy и ffmpeg.
Текст сцен правится в `build_scenes()`.
